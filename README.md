# 🇮🇳 SkillBridge India

A full-stack skill development and job portal platform connecting students, instructors, employers, and administrators in one ecosystem.

## 📌 Overview

SkillBridge India is a modern MERN-based platform designed to bridge the gap between skill learning and employment opportunities.

## The platform allows:

- 🎓 Students to enroll in courses, track progress, earn certificates, and apply for jobs
- 👨‍🏫 Instructors to create and manage courses
- 🏢 Employers to post jobs and review applicants
- 🛠️ Admins to manage the entire platform

This project demonstrates real-world full-stack development concepts including authentication, role-based access control, REST APIs, file uploads, dashboards, and deployment.

## 🚀 Features
- Authentication & Authorization
- Courses & Skills Module
- Certification Module
- Auto-generated Certificates
- Jobs Module
- Dashboards
- Tech Stack
  
## Layer	Technology
- Frontend	HTML, Tailwind CSS, Vanilla JavaScript
- Backend	Node.js, Express.js
- Database	MongoDB, Mongoose
- Authentication	JWT, bcrypt
- File Uploads	Multer
- Email Service	Nodemailer
- Deployment	Render (Backend), Netlify (Frontend)
